
# Basic Chatbot - CodeAlpha Internship

## Project Overview
This is a simple rule-based chatbot developed using Python
as part of the CodeAlpha Python Programming Internship.

The chatbot interacts with users through the terminal and
provides predefined responses to specific messages.

## Features
- Greets the user.
- Responds to "How are you?"
- Tells the user its name.
- Responds to "Thank you".
- Provides help instructions.
- Exits when the user types "bye".
- Handles unrecognized messages.

## Technologies Used
- Python 3
- VS Code

## Concepts Used
- Functions
- While loops
- If-elif-else statements
- User input and output
- String methods

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python chatbot.py
